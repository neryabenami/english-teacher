# מדברים אנגלית

אפליקציה חינמית ללימוד אנגלית לדוברי עברית. היא מותאמת ל־iPhone, עובדת גם בלי אינטרנט ונשמרת על המכשיר (PWA).

## התקנה על iPhone

1. פותחים את הקישור ב־Safari.
2. לוחצים על כפתור השיתוף ואז על "הוסף למסך הבית".
3. האפליקציה נפתחת במסך מלא ועובדת גם בלי אינטרנט.

## מה יש באפליקציה

כרטיסיות עם חזרות חכמות (SM-2), 20 נושאים, סלנג ו־Real English, סיפורים עם תרגום בלחיצה ומשמעות לפי הקשר, הקראה בארבע מהירויות, מילון מקומי, מבחנים, משחקים, שיחה עם מורה מקומי שמתקן טעויות (וחיבור אופציונלי ל־Google Gemini בשכבה החינמית), סטטיסטיקות, Streak ומצב כהה.

## מבנה הקוד

1. `js/data.js` מכיל את מאגר התוכן: מילים, סלנג, ביטויים, סיפורים ותרחישי שיחה.
2. `js/lex.js` הוא מילון כללי מקומי לקריאה אינטראקטיבית.
3. `js/core.js` כולל אחסון מקומי, חזרות חכמות, הקראה, בדיקת דקדוק וספקי AI שאפשר להחליף.
4. `js/app.js` הוא ממשק המשתמש: ניתוב, מסכים ופעולות.
5. `sw.js` שומר את כל האפליקציה במכשיר לשימוש Offline.

אין שלב בנייה ואין תלות בספריות. כדי להוסיף תוכן עורכים את `js/data.js`. אחרי שינוי בקבצים כדאי לעדכן את `VERSION` ב־`sw.js`, כדי שהמכשירים יורידו את הגרסה החדשה.
